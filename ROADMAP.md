# OrbitGraph roadmap

## Current development: v1.3.0

- [x] Desktop, touch, and keyboard camera navigation
- [x] Responsive mobile camera controls
- [x] Keyboard accessibility
- [x] PNG and JSON exports
- [x] React ref API for interactions and exports
- [x] Test coverage and documentation for v1.1 APIs

## Delivered: v1.2.0 — scalable graph intelligence

- [x] Move force simulation to a Web Worker
- [x] Run expensive graph analysis outside the main UI thread
- [x] Connected-component and community detection
- [x] Centrality metrics such as degree, weighted degree, and PageRank
- [x] Optional visual highlighting for communities and important nodes
- [x] Analysis benchmarks for large graphs

## v1.3.0 — collaborative exploration

- [x] Advanced node metadata and relationship-weight filtering
- [x] Serializable shared views, annotations, and bookmarks
- [x] Framework-agnostic tooltip and details rendering hooks
- [x] CSV, JSON-LD, Cytoscape, and Neo4j data import helpers
- [x] Timeline, bipartite, geographic, DAG, and Sankey layout modes
- [ ] Community cluster meshes with expand/collapse animation
- [ ] Automatic level-of-detail and runtime telemetry
- [ ] Synchronized semantic table/tree view

## Future

- [ ] Additional renderer adapters and framework integrations
- [ ] Advanced theming and styling hooks
- [ ] AR/VR exploration experiments
- [ ] Server-side graph transformation utilities

The roadmap describes intent, not a release contract. Feedback and contributions are welcome through GitHub issues and discussions.
